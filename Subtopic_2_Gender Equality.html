The impact of AI Adoption on Canadian Wage - Subtopic 2: Gender Equality¶

Did AI had an influence on wages and employments regarging gender equality?¶

Goals¶

In this analysis, we aim to investigate the impact of AI on gender equality in tech-related jobs. To achieve this goal, we intend to:

  • Identify key patterns of gender inequality in employment over the years.
  • Identify key patterns of gender inequality in wages over the years.
  • Determine which occupations are the most discriminatory.

Introduction¶

Context/Hypothesis: Before our analysis started, we hypothesized that AI would make the wage gap slightly fluctuates in an unknown direction and that the employment gap would be reduced even a little.

Problem Statement¶

We wish to answer the following answers are the following:

  • Do technology-related jobs in Canada continue to show a gender gap in employment and wages?
  • What is the behaviour of these gender gaps over the last 13 years?
  • Has the widespread introduction of AI had a disproportionate effect on employment trends or wages between men and women in these occupations?

Significance: The results can guide policy decisions related to recruitment, pay equity, and advancement opportunities by identifying which occupations remain most unequal.

def subset_to_long(df_subset, gender_label):
    df_tmp = df_subset.dropna(how="all").reset_index(drop=True)
    # Layout:
    # row 0: "15 years and over"
    # row 1: 2012, 2013, ...
    # row 2: "Persons in thousands"
    # row 3+: data rows
    years = df_tmp.iloc[1, 1:].tolist()
    data = df_tmp.iloc[3:, 1:].copy()
    data.columns = years

    long_df = data.melt(var_name="Year", value_name="Employment")
    long_df["Gender"] = gender_label

    long_df["Year"] = pd.to_numeric(long_df["Year"], errors="coerce")
    long_df["Employment"] = pd.to_numeric(long_df["Employment"], errors="coerce")
    long_df = long_df.dropna(subset=["Year", "Employment"]).reset_index(drop=True)
    return long_df

# Convert each block to long format
total_long = subset_to_long(df_total, "Total")
men_long   = subset_to_long(df_men,   "Men")
women_long = subset_to_long(df_women, "Women")

# Combine all into one tidy dataset
gender_long = pd.concat([total_long, men_long, women_long], ignore_index=True)

# Pivot: rows = Year, columns = Gender
pivot = gender_long.pivot_table(
    index="Year",
    columns="Gender",
    values="Employment",
    aggfunc="sum"
).reset_index()

pivot.columns.name = None

# Compute metrics
pivot["Women_Share_%"] = (pivot["Women"] / pivot["Total"]) * 100
pivot["Gender_Employment_Gap_%"] = ((pivot["Men"] - pivot["Women"]) / pivot["Men"]) * 100

We unpacked the dataset into two subsets: one for the hourly wages and one for the weekly wages.

Our next step is to do data cleaning and transformation:

Data Cleaning and Data Transformation¶

To clean our data, we are going to create a function that:

  • Turns the rows into columns and group them into a single column named Year;
  • Turns the values in Year and data into numerical data.
  • Drop the missing values with respect to Year and ratio.

We will apply that function to each of the two previous datasets, merge those datasets and we will create three new columns: Hourly_Wage_Gap_%, Weekly_Wage_Gap_%, Implied_Hours_Ratio.

In [7]:
warnings.filterwarnings("ignore")


# ---------------------------------
# Helper: reshape wide block → long by Year
#   Layout inside each block:
#      row 0: NaN
#      row 1: "Women+"
#      row 2: "15 years and over"
#      row 3: 2012, 2013, 2014, ...
#      row 4: NaN
#      row 5+: occupation + ratio values
# ---------------------------------
def reshape_ratio_block(df_block, value_name):
    # Row 3 contains year labels across columns 1..end
    years = df_block.iloc[3, 1:].tolist()
    
    # Data rows start at row 5 (0-based index)
    data = df_block.iloc[5:, 1:].copy()
    data.columns = years  # set year labels as column names
    
    # Occupation names live in column 0, same row indices (5+)
    data["Occupation"] = df_block.iloc[5:, 0].values
    
    # Melt wide → long
    long_df = data.melt(
        id_vars="Occupation",
        var_name="Year",
        value_name=value_name
    )
    
    # Clean types
    long_df["Year"] = pd.to_numeric(long_df["Year"], errors="coerce")
    long_df[value_name] = pd.to_numeric(long_df[value_name], errors="coerce")
    
    # Drop rows missing year or ratio
    long_df = long_df.dropna(subset=["Year", value_name]).reset_index(drop=True)
    
    return long_df


# Convert hourly & weekly to long
hourly_long = reshape_ratio_block(df_hourly, "Hourly_ratio")
weekly_long = reshape_ratio_block(df_weekly, "Weekly_ratio")


# Merge on Year + Occupation
wages = pd.merge(
    hourly_long,
    weekly_long,
    on=["Year", "Occupation"],
    how="inner"
)

# ---------------------------------
# Compute wage gap metrics (Methods section)
#   Ratios are Women-to-Men, so Men = 1.0
# ---------------------------------
wages["Hourly_Wage_Gap_%"] = (1 - wages["Hourly_ratio"]) * 100
wages["Weekly_Wage_Gap_%"] = (1 - wages["Weekly_ratio"]) * 100
wages["Implied_Hours_Ratio"] = wages["Weekly_ratio"] / wages["Hourly_ratio"]

Conclusion¶

Our analysis demonstrated that over the years, the employment gap between men and women have been reducing over time which is would be amazing especially if it was majoritarily due to the introduction of AI in the different tech-based occupations. Also, we found out that the wage gap between men and women has not really observed a steady pace which keeps questions lingering in our head such as: Is there something intefering with AI so that it negates its effects on gender gap? This analysis will allow employers to make better decisions regarding the process of making disappear the gender inequality.

Key takeaways¶

In this case, we analyzed wage and employment gaps over the years and occupations using python. Specifically, we:

  • Cleaned data related to wage and employment gap from the years 2012 to 2024;
  • Grouped the data according to the data it is supposed to represent (wage/employment gap);
  • Used visualizations and summary statistics to identify patterns.

The results encourage the fact that AI introduction is prone to reduce the employme gap difference but it is less certain for the wage gap difference because of the oscillations. Thus, the introduction of AI should be investigated further before making any real affirmations.
